# ReptiBud – Logbook Mode (v0.1)

ReptiBud is a mobile-first web app for tracking basic reptile care.
This version is intentionally minimal and built for internal dogfooding.

## What This Version Is
- A simple logbook for reptile care
- Focused on speed, clarity, and daily usage
- Built to replace notes, memory, and ad-hoc tracking

## Core Features
- Pet management (CRUD)
- Feeding tracker
- Basic care / health timeline

## What This Version Is NOT
- No AI
- No analytics
- No charts
- No social features
- No advanced health logic
- No database (JSON storage only)

## Product Philosophy
- Dogfooding first
- Ship fast, iterate often
- Avoid premature abstraction
- Optimize for daily use, not demos

## Tech Stack
- Next.js (App Router)
- CSS Components with BEM
- Supabase Auth
- JSON file storage per pet (temporary)
